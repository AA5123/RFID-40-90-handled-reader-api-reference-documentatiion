## Overview

Manage the device's WiFi and Ethernet connections. The device supports both interfaces simultaneously for flexible networking.

## Commands

| Command | Description |
|---|---|
| [`get_eth`](#get_eth) | Retrieve Ethernet status including link state, speed, IP address, security |
| [`get_wifi`](#get_wifi) | Retrieve WiFi status including connected SSID, IP, signal strength, security type |
| [`set_wifi`](#set_wifi) | Configure WiFi access point, security (WPA2/WPA3/Enterprise), and IP settings |
| [`delete_wifi_profile`](#delete_wifi_profile) | Remove a saved WiFi profile by SSID |
