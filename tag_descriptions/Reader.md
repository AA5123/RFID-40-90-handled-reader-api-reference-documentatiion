## Overview

Retrieve and monitor device identity, version information, and hardware specifications. Essential for device tracking and compatibility verification.

## Commands

| Command | Description |
|---|---|
| `get_version` | Query device model, serial number, SKU, and firmware versions |
| `get_status` | Retrieve current device operational status |

## Information

Device identity includes:
- Hardware model (RFD40, RFD90)
- Serial number and SKU
- Main firmware version
- Component firmware versions (scanner, radio, IOTC)
